# Πακέτα μετάφρασης

Κάθε γλώσσα πέρα από τα ελληνικά και τα αγγλικά ζει σε ένα αρχείο `<κωδικός>.json`
εδώ μέσα και κατεβαίνει **μόνο όταν ο χρήστης επιλέξει τη γλώσσα**. Έτσι το
`index.html` δεν βαραίνει για όσους δεν τη χρησιμοποιούν.

## Μορφή

```json
{
  "lang": "de",
  "ui":    { "<κλειδί TR>": "κείμενο" },
  "meals": { "<id συνταγής>": { "n": "...", "ing": [...], "steps": [...],
                                "wine": "...", "plate": "..." } },
  "fest":  { "f0": { "n": "...", "d": "..." } },
  "prep":  { "fasolada": { "msg": "..." } },
  "sweets":{ "keik:0": { "n": "...", "ing": [...], "steps": [...] } }
}
```

## Κανόνες

- Το `lang` **πρέπει** να ταιριάζει με το όνομα του αρχείου, αλλιώς το πακέτο απορρίπτεται.
- Οι πίνακες (`ing`, `steps`, `menu`, `tl2`) περνούν **μόνο αν έχουν ακριβώς το ίδιο
  πλήθος στοιχείων** με τα ελληνικά. Διαφορετικό πλήθος ⇒ αγνοείται σιωπηλά και
  εμφανίζονται τα αγγλικά.
- Ό,τι λείπει πέφτει στα **αγγλικά** — ποτέ στα ελληνικά. Ένα ημιτελές πακέτο
  δείχνει μισά γερμανικά και μισά αγγλικά, ποτέ ελληνικά σε ξένο χρήστη.
- Μια γλώσσα εμφανίζεται στα κουμπιά **μόνο** αφού καταχωρηθεί στο `LANGS`
  (`index.html`). Μην την καταχωρήσεις πριν υπάρχει το αρχείο της.
- Σε κάθε αλλαγή πακέτου, αύξησε το `VERSION`/`CACHE` στο `service-worker.js`.
