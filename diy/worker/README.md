# Βοήθεια με φωτογραφία — ο ενδιάμεσος worker

Ο χρήστης κολλάει σε ένα βήμα, τραβά φωτογραφία, και παίρνει οδηγία για το τι
να κάνει. Αυτός ο φάκελος είναι το κομμάτι που **δεν** μπορεί να ζει μέσα στη
σελίδα.

## Γιατί χρειάζεται

Η εφαρμογή είναι στατική σελίδα στο GitHub Pages: ο κώδικάς της είναι ορατός σε
όλους. Η ανάλυση εικόνας απαιτεί κλειδί API. **Κλειδί μέσα στη σελίδα σημαίνει
ότι το βλέπει ο καθένας και το χρεώνεται.** Ο worker κρατά το κλειδί, ελέγχει
ποιος τον καλεί, βάζει όρια χρήσης και μόνο μετά προωθεί το αίτημα.

```
Σελίδα  ──φωτογραφία + βήμα──►  Worker  ──κλειδί──►  Claude API
                               (κρατά το κλειδί,
                                όρια, έλεγχος origin)
```

## Εγκατάσταση

Χρειάζεσαι λογαριασμό Cloudflare (δωρεάν) και ένα κλειδί από το
[console.anthropic.com](https://console.anthropic.com).

```bash
cd diy/worker
npm install

# 1. Το κλειδί μπαίνει ως secret — ΠΟΤΕ μέσα σε αρχείο του repository
npx wrangler secret put ANTHROPIC_API_KEY

# 2. Μετρητής ορίων χρήσης (συνιστάται — δες «Κόστος» παρακάτω)
npx wrangler kv namespace create RL
#    Αντίγραψε το id που τυπώνει στο wrangler.toml, στο [[kv_namespaces]]

# 3. Ανέβασμα
npx wrangler deploy
```

Το `wrangler deploy` τυπώνει τη διεύθυνση, κάτι σαν
`https://diy-help.<λογαριασμός>.workers.dev`.

## Σύνδεση με την εφαρμογή

Στο `diy/index.html` βρες τη γραμμή:

```js
const HELP_ENDPOINT = '';
```

και βάλε τη διεύθυνση του worker. Αύξησε το `VERSION` στο `diy/sw.js` και κάνε
push. Τέλος.

**Για δοκιμή χωρίς αλλαγή κώδικα:** άνοιξε τη σελίδα με
`?help=https://…workers.dev`. Η διεύθυνση αποθηκεύεται στη συσκευή σου μόνο.
Με σκέτο `?help=` καθαρίζει.

## Κόστος — διάβασέ το πριν το ανοίξεις σε όλους

Κάθε φωτογραφία είναι μια πραγματική χρέωση στον λογαριασμό σου.

| | |
|---|---|
| Μοντέλο | `claude-opus-5` — $5 ανά 1εκ. tokens εισόδου, $25 ανά 1εκ. εξόδου |
| Μία φωτογραφία 1024 px | ~1.050 tokens εικόνας + ~600 κειμένου |
| Απάντηση | ~600–1.200 tokens |
| **Εκτίμηση ανά ερώτηση** | **περίπου 2–4 λεπτά του ευρώ** |

Δηλαδή 1.000 ερωτήσεις ≈ 20–40 €. Χωρίς όρια, ένα κακόβουλο script μπορεί να
στείλει χιλιάδες αιτήματα σε λίγα λεπτά.

**Προστασία:**
- Το KV binding `RL` επιβάλλει τα όρια ανά IP (`LIMIT_PER_HOUR`, `LIMIT_PER_DAY`
  στο `wrangler.toml`). **Χωρίς αυτό δεν υπάρχει κανένα όριο.**
- Το `ALLOWED_ORIGIN` δέχεται αιτήματα μόνο από τη σελίδα σου.
- Βάλε **spend limit** στον λογαριασμό Anthropic. Είναι το μόνο απόλυτο φρένο.

**Για φθηνότερη λειτουργία** άλλαξε στο `src/index.js`:
- `effort: 'low'` αντί για `'medium'` — αισθητά λιγότερα tokens εξόδου
- `MODEL = 'claude-sonnet-5'` — $2/$10 αντί για $5/$25

## Ασφάλεια περιεχομένου

Το system prompt στο `buildSystem()` επιβάλλει:
- να μην εικάζει για ό,τι δεν φαίνεται καθαρά στη φωτογραφία
- να λέει ρητά πότε χρειάζεται αδειούχος επαγγελματίας (πίνακας, αέριο,
  καυστήρας, φέροντα στοιχεία) — τότε επιστρέφει `callPro: true` και η
  εφαρμογή το δείχνει με κόκκινο πλαίσιο
- να μην προτείνει ποτέ παράκαμψη μέτρου ασφαλείας, γείωσης ή ρελέ
- σε καμένα ηλεκτρολογικά, να στέλνει τον χρήστη στη γενική ασφάλεια και σε
  ηλεκτρολόγο

**Μην χαλαρώσεις αυτούς τους κανόνες.** Είναι ο λόγος που η λειτουργία μπορεί
να υπάρχει σε εφαρμογή που δίνει οδηγίες για ρεύμα και νερό.

## Ιδιωτικότητα

Η φωτογραφία σμικρύνεται στη συσκευή στα 1024 px πριν φύγει, περνά από τον
worker και δεν αποθηκεύεται πουθενά — ούτε στον worker, ούτε σε KV, ούτε σε
logs. Το μήνυμα στην εφαρμογή το λέει στον χρήστη και τον προτρέπει να μη
φωτογραφίζει πρόσωπα ή έγγραφα.

## Έλεγχος ότι δουλεύει

```bash
curl -X POST https://<ο worker σου>.workers.dev \
  -H 'Content-Type: application/json' \
  -H 'Origin: https://georgebokos.github.io' \
  -d '{"lang":"el","image":"<base64 jpeg>","mime":"image/jpeg",
       "task":{"name":"Αλλαγή πρίζας"},
       "step":{"n":3,"total":10,"title":"Ξεβίδωσε το καπάκι"}}'
```

Επιστρέφει `{"answer":"…","callPro":false}`.
