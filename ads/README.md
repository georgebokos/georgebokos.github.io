# Διαφημιστικά — Google Ads (YouTube και υπόλοιπο δίκτυο)

## Τι είναι εδώ

| Αρχείο | Πού μπαίνει στο Google Ads |
|---|---|
| `text-assets.txt` | Τίτλοι (≤30 χαρ.) και περιγραφές (≤90 χαρ.), ΕΛ και ΕΝ |
| `ad-landscape-*.png` | Εικόνα 1.91:1 — 1200×628 |
| `ad-square-*.png` | Εικόνα 1:1 — 1200×1200 |
| `ad-portrait-*.png` | Εικόνα 4:5 — 1200×1500 |
| `video-portrait-*.mp4` | Βίντεο 9:16 — για YouTube Shorts |
| `video-landscape-*.mp4` | Βίντεo 16:9 — για in-stream YouTube |
| `video-square-*.mp4` | Βίντεο 1:1 — για feed |

Τα βίντεο είναι **18 δευτερόλεπτα** — πάνω από το ελάχιστο των 10 που ζητά η Google
και μέσα στο εύρος που δουλεύει καλά σε Shorts.

## Πώς αναπαράγονται

```bash
python3 ads/text_assets.py            # κείμενα, με έλεγχο ορίων χαρακτήρων
python3 ads/images.py                 # και οι τρεις αναλογίες, ΕΛ και ΕΝ
python3 ads/video.py                  # και τα έξι βίντεο (~8 λεπτά)
python3 ads/video.py el portrait      # ένα μόνο
```

Οι φωτογραφίες αντλούνται από τα ίδια αρχεία `images/` της εφαρμογής και η σκηνή του
ψυγείου από το `store/screenshots-*/8-psygeio.png`, οπότε η διαφήμιση δείχνει
**την πραγματική εφαρμογή**.

## Δεν έχουν ήχο

Τα βίντεο είναι βουβά. Στο YouTube ο ήχος βοηθά, αλλά η μουσική χρειάζεται πηγή με
καθαρή άδεια — δεν βάζω κάτι με αμφίβολα δικαιώματα σε πληρωμένη καμπάνια. Αν θέλεις
ήχο, οι επιλογές είναι η βιβλιοθήκη ήχου του YouTube ή εκφώνηση.

## Τι πρέπει να ξέρεις για την καμπάνια

**Δεν διαφημίζεις εφαρμογή «στο YouTube».** Ο τύπος καμπάνιας είναι **App**, και η
Google μοιράζει τις διαφημίσεις μόνη της σε YouTube, Αναζήτηση, Play, Discover και
Display. Δεν επιλέγεις τοποθετήσεις ούτε λέξεις-κλειδιά.

Πριν ξεκινήσεις:

1. Λογαριασμός **Google Ads** και σύνδεσή του με το **Play Console**
   (Play Console → Settings → Linked accounts). Χωρίς αυτό δεν μετρώνται εγκαταστάσεις.
2. Καμπάνια → **App** → App installs → επιλογή της `com.fooddaily.app`.
3. Ανέβασμα των παραπάνω δημιουργικών.
4. Ημερήσιος προϋπολογισμός. Ο εμπειρικός κανόνας της Google είναι
   **δεκαπλάσιος του στόχου κόστους ανά εγκατάσταση** — αλλιώς ο αλγόριθμος δεν έχει
   αρκετά δεδομένα για να μάθει.

⚠️ **Οι εγκαταστάσεις δεν είναι το ζητούμενο — οι συνδρομές είναι.** Με σκέτη μέτρηση
εγκαταστάσεων η Google βελτιστοποιεί για κόσμο που κατεβάζει και δεν πληρώνει ποτέ.
Για να βελτιστοποιεί προς συνδρομητές χρειάζεται μέτρηση συμβάντων εντός εφαρμογής,
δηλαδή **Firebase / GA4 SDK στην Capacitor έκδοση** — που σήμερα δεν υπάρχει.

## Πηγή φωτογραφιών και δικαιώματα

Οι φωτογραφίες προέρχονται από το `images/` της εφαρμογής. Ο κανόνας του project είναι
ότι μπαίνουν **αποκλειστικά εικόνες από Wikimedia Commons** με ελεύθερη άδεια.

⚠️ Το `_prepared/image-credits.json` τεκμηριώνει **45 από τις 379** εικόνες — αυτές που
προστέθηκαν πρόσφατα. Οι τέσσερις που χρησιμοποιούν οι διαφημίσεις
(`giouvetsi`, `pastitsio`, `souvlakia`, `moussaka`) είναι παλαιότερες και **δεν έχουν
καταγεγραμμένη προέλευση**. Σε πληρωμένη καμπάνια αυτό έχει σημασία: η Google ελέγχει
τα δημιουργικά και μια εικόνα με αμφίβολα δικαιώματα μπορεί να απορριφθεί, ενώ ο
δικαιούχος μπορεί να στραφεί εναντίον σου. **Επιβεβαίωσε την άδειά τους πριν πληρώσεις
για προβολή** — ή άλλαξέ τες με εικόνες που έχουν τεκμηρίωση.
