# Βίντεο «δύο φίλες στο τηλέφωνο»

`ads/call.py` → `call-fooddaily-el.mp4` (16,9΄΄) και `call-fooddaily-en.mp4`

Δεν είναι διαφήμιση, είναι **σκηνή**. Η εφαρμογή δεν παρουσιάζεται — εμφανίζεται
μόνο ως η απάντηση στο «πώς το έκανες;». Η σύσταση από φίλη περνάει· η
διαφήμιση όχι.

## Ο διάλογος

| | |
|---|---|
| Ελένη | Τι έφτιαξες σήμερα; |
| Μαρία | Κόκορα κρασάτο. |
| Μαρία | Και μιλφέιγ. |
| Ελένη | Πλάκα κάνεις. |
| Ελένη | Πώς πρόλαβες; |
| Ελένη | Είχες τα υλικά; |
| Μαρία | **Όχι.** |
| Μαρία | Τα είδα στο FoodDaily και τα έστειλα στον άντρα μου. |
| Μαρία | Τα έφερε. Τόσο απλά. |
| Ελένη | Στείλε μου τη συνταγή. |
| Μαρία | Περίμενε… |

Τα δύο πιάτα είναι επίτηδες **δύσκολα** (κόκορας κρασάτος: 12 υλικά, 11 βήματα ·
μιλφέιγ: 10 υλικά, 10 βήματα). Αν ήταν μακαρόνια, δεν θα υπήρχε λόγος να
ρωτήσει η φίλη «πώς;» — και χωρίς αυτή την ερώτηση δεν υπάρχει βίντεο.

Το «Όχι.» έχει τη μεγαλύτερη παύση πριν και μετά. Είναι η στροφή.

## ⚠️ Το βίντεο τελειώνει σκόπιμα στο «Περίμενε…»

Από εκεί και πέρα **κολλάς τη δική σου οθόνη**:

1. Μπαίνεις στην εφαρμογή
2. Πας στη συνταγή (κόκορας κρασάτος)
3. Πατάς **κοινοποίηση συνταγής**
4. Δείχνεις και την **αποστολή των υλικών**

Πραγματική οθόνη, όχι σχεδιασμένη — αυτό είναι το αποδεικτικό και ο λόγος που
δουλεύει το βίντεο. Το μοντάζ είναι απλό: βάζεις το `call-fooddaily-el.mp4`
πρώτο και από πίσω το βίντεο της οθόνης.

Ιδανική συνολική διάρκεια: **25–30 δευτερόλεπτα**. Αν η οθόνη τραβήξει
περισσότερο, κόψ' την — δεν χρειάζεται να φανεί κάθε πάτημα.

## Λεζάντα

```
— Είχες τα υλικά;
— Όχι. Τα έστειλα στον άντρα μου μέσα από την εφαρμογή.

Λίστα υλικών και κοινοποίηση συνταγής, με ένα πάτημα.
376 ελληνικές συνταγές — Ελληνικά, English, Deutsch.

📲 fooddaily.github.io
(σύνδεσμος και στο προφίλ)

#συνταγες #μαγειρικη #τιμαγειρευουμεσημερα #κοκκορας #μιλφειγ #fooddaily
```

## Παραλλαγές για επόμενες φορές

Αλλάζεις **μόνο** τη λίστα στο `script()` του `ads/call.py`. Ο σκελετός μένει:
δύσκολο πιάτο → δυσπιστία → «είχες τα υλικά;» → «όχι» → η εφαρμογή → κοινοποίηση.

Άλλα ζευγάρια πιάτων που κρατούν την ίδια απορία:
- Αρνί κλέφτικο + Τσουρέκι
- Μπεφ μπουργκινιόν + Εκλέρ
- Οσομπούκο με ριζότο + Τούρτα Red Velvet
- Γαλοπούλα γεμιστή + Κορμός Χριστουγέννων (για τις γιορτές)

Άλλαξε και τα ονόματα, να μη δείχνει ίδιο βίντεο.
